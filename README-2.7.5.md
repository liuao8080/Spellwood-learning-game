# Spellwood 词灵对决 2.7

原创英语卡牌战斗游戏。六个年级，432道原创题，12张卡牌、三套预组套牌、三个自主决策电脑角色，以及本机复习与挑战榜。

## 直接运行

解压后，双击 `dist/index.html` 即可开始。图片位于同目录的 `assets`，请保持目录完整。游戏无需联网后端，打开后可离线运行。配乐、图片和Three.js随成品一起保存。题目英语音频已一同保存，不依赖系统语音包；只有素材失败时才尝试系统朗读。

浏览器对 `file://` 的持久存储支持不同，第一次使用请通过设置导出备份，或通过普通静态服务器运行：

```sh
python3 -m http.server 4173 --directory dist
```

在线站点由使用者自行管理分享范围；当前交付已按用户要求公开访问。公开游戏内容不会上传本机昵称、学习记录或挑战记录。游戏没有网络写入、广告、聊天或账号功能。

## 开发与复现

需要 Node.js 20 或更高版本。运行成品无需联网加载库；Three.js已打包用于本地3D粒子和魔法效果。TypeScript、esbuild和Node类型定义仅用于开发检查。

```sh
npm ci
npm run typecheck
npm test
npm run build
```

- `src/cards.mjs`：卡池、套牌、角色、年级
- `src/engine.mjs`：不可变战斗状态、合法动作、确定性随机数、有界斩杀搜索、公开威胁检查与多步防御AI
- `src/learning.mjs`：知识记录、间隔复习、首答记录与版本迁移、存档验证
- `src/questions.json`：432题，可独立编辑
- `src/app.mjs`：界面、浏览器存档、合成音效、朗读
- `src/style.css`、`src/battle-v2.css`：全宽战场、近景卡牌、桌面和平板/手机重排
- `src/av/effects.mjs`：Three.js光效、粒子、弹道与冲撞回位；不支持WebGL时使用Canvas降级
- `src/av/audio.mjs`：音乐、音量与原创音效；首次点击后解锁
- `scripts/make_music.py`：原创60秒循环配乐的可复现合成源码
- `src/types.d.ts`：核心接口契约；核心模块执行JSDoc类型检查
- `scripts/build.mjs`：把样式、逻辑和题库合并为可离线打开的HTML
- `tests/engine.test.mjs`：规则、安全、题库、学习与模拟测试

## 规则

双方18生命，每方4个随从位置、7张手牌上限、20张预组牌库。能量从1增加到6。新召唤随从下一回合行动，“迅捷”例外；“守卫”优先承受普通攻击。交战同时结算伤害；牌库耗尽后逐步受到疲劳伤害。

当前规则每局最多4次词灵仪式，每回合最多一次。答对：灵光抽1牌、火花指定敌人2伤害、守护恢复3生命。答错仍获得1护甲。普通出牌和攻击无需答题，没有答题倒计时。Ember、Moss、Luna为电脑角色，分别偏进攻、控场、资源成长，不读取你的隐藏手牌或未来牌库顺序；它们也各有4次自主选择的仪式。

排行榜只记录本浏览器真正完成的最近200局（所有年级合计），列表最多显示30条。较早成绩可能移出榜单，长期留存请定期导出备份。同年级、规则版本内显示各昵称在同一种子/套牌/对手组合的个人最佳；不同组合只用于回顾，不能当作公平的同场竞技排名。本地数据不是服务器认证的比赛记录。

熟练要求在三个不同日期连续答对。同日重复练习不增加熟练阶段；错后改对至少1天后才再次到期，避免立即反复出现。学习记录是练习反馈，不是能力诊断，也不是指定教材的完整覆盖证明。

## 存档与隐私

数据仅写入当前浏览器localStorage，新版独立键为 `spellwood.save.v2`。第一次使用新版会在取得写入权后复制有效的旧 `spellwood.save.v1`，原文保留；此后不自动合并新旧页面，升级后请关闭旧页面。设置中可导出JSON并在另一浏览器恢复；导入先验证、再明确确认替换。无法读取的原始存档保留为恢复副本。没有自动跨设备同步，也没有学生账号。

昵称无需真实姓名。不要填写学生个人信息。导出的存档包含昵称和学习情况，请自行保管，不建议公开分享。

## 使用边界

没有真实联网对战、全服排名或课堂管理后台。所有12张卡牌和套牌一开始即可使用，没有抽卡付费、广告或体力机制。对战节奏与难度继续通过实际试玩调整；尚无真实儿童或教师课堂试验，不能把自动对战结果当作儿童胜率。

## 素材与许可

场景和12张独立卡牌插画为本项目原创生成；提示音由Web Audio实时合成。没有复制炉石或学而思的商标、美术、音频或题库。详细说明见 `THIRD_PARTY_NOTICES.txt`。参考研究与真实测试范围在交付报告中列明。

## 第二版声音与动效

首次点击后会解锁音乐与音效。顶部音符可切换背景音乐；设置中可独立开关音乐和音效、调整两个音量，并开启减少动态效果。首次读取第一版没有音乐设置的旧存档时，会初始化新的声音体验；学习数据、未完成对局和已完成记录保持兼容。

动作在引擎中只提交一次，表现层按预备、飞行/冲撞、命中、归位/消散的顺序演出。刷新中途会从已经保存的真实状态恢复；重开或返回会取消尚未完成的旧动画。

## 2.1 课程题库更新

题库版本 `pep1-2026.1`：参照人教版英语（一年级起点，吴欣主编）1–6年级上下册核心单元知识，自编432题，12册72单元各6题。不是教材官方题库，不收录课文或扫描页。知识范围索引在 `src/curriculum.json`，清晰覆盖表在 `content/课程覆盖表.csv`。一年级48词语+24生活短句，二年级36词语+24表达+12小语境，三至六年级每级36词语+12表达+24语境。数量是练习项目数，不等于掌握的单词数。

营地与手册支持全年级、上下册和单元范围。相同种子、年级、范围和题库版本决定固定题序；排行榜同时区分范围与题库。旧学习统计迁入archivedMastery，旧局错题索引存入archivedReview；不把旧题答对次数当成新题熟练度。进行中的旧局保留战场、题序索引和得分计数，后续题面使用修订题库继续，并归入旧版衔接记录。旧挑战重赛明确使用新版题库另计分。

核心逻辑与应用测试覆盖正确和错误答题完整异步路径、重复点击、90种课程范围的确定性、同日复习、旧档二次导入和分榜。类型检查仅覆盖标注的核心模块，不能替代浏览器实机体验。

## 2.2 独立卡画与操作手感

12张牌现在各有独立画面：新增芽芽精灵、青苔幼灵、远古岩灵，以及星火、春生、月之启示三张法术的原创插画。新增插画以640px WebP交付，总计约700KB；原始生成图保留在制作工作区。

营地缩减装饰性间距而保持可读字号；手牌增加鼠标浏览按钮，选牌后保留横向位置，小屏选牌自动将操作区带到视野。窄屏把仪式按钮移到手牌上方。法术增加可见拖尾与有明暗面的旋转晶体；护盾增加半透明立体六角外壳。WebGL2可用时使用Three.js材质和网格；不可用时使用同一原创几何思路的Canvas软件投影，不影响规则。减少动态仍保留结果提示并跳过位移动画。

## 2.3 有限仪式与战术对手

新开对局采用规则2.0：双方每局各有4次仪式，每回合最多一次。玩家通过英语答题唤醒效果，错误仍得1护甲并消耗此次仪式；电脑根据场面在抽牌、伤害和治疗之间自主选择。战斗结束后的词灵手册仍可不限次练习。这一取舍将战斗中英语检查限制在最多4次，避免每回合无限施法拖长对战。

电脑决策会遮蔽双方未来牌库顺序与对手隐藏手牌，未知抽牌不能被当成保证胜利的卡牌。它使用固定节点预算的本回合斩杀搜索、公开威胁检查和多步安全终点搜索，再按进攻/控场/资源权重评估。搜索有界，不保证穷尽全部复杂局面，也不等于商业游戏AI质量。

当前对战分只由胜负、剩余生命与回合决定，英语正确次数另行记录，避免故意拖延获胜来刷题分。旧1.0对局保留原资源与计分规则，完成后进历史记录；新旧规则不混排，旧学习档案继续保留。

本版也清除了Canvas最后一帧的晶体残影。减少动态时，退场单位使用有归属的静态战报，存活者的伤害数字对准当前位置。答后可点击“听英语”，朗读时降低背景音乐；离开标签页不会因后续重绘自动重新播放音乐。

可用 `node scripts/benchmark-ai.mjs 60` 重复满场合成局面的CPU检查。它不是浏览器FPS，也不是儿童胜率。所有版本仍需真实试玩验证趣味和可理解性。

## 2.4 预制英语语音与键盘修复

432题的答前/答后英语文本共生成778段去重语音，约32分钟、12.1MB单声道MP3。用本地Kokoro v0.19 af合成声音，未传输学生数据，也没有客户端付费API。选项之间有0.4秒间隔，空缺位置保留0.65秒停顿，不提前读出答案。声音依据与模型哈希见 `content/speech-provenance.json`。

点“听英语”播放，播放中可再次点“停止朗读”；切换题目、作答、关闭窗口、关闭朗读或收到页面隐藏事件时会停止。朗读时压低配乐，结束后恢复。系统朗读仅作素材无法播放时的后备，设备兼容性仍需实际验证。

修复了模态关闭后返回入口、年级切换、选牌的键盘焦点丢失。键盘选牌或选随从后会进入施放/目标操作；隐藏标签页后返回也会恢复电脑回合调度。战报额外保留单位下沿的空间，避免压住准备攻击标记。

可选再生成音频：从官方sherpa-onnx文档取得kokoro-en-v0_19模型，安装 `sherpa-onnx==1.13.8` 与numpy，再运行 `python3 scripts/make_speech.py --model /path/to/kokoro-en-v0_19 --cache /path/to/output`。生成物先写入独立输出目录；校验完成后再将encoded文件与speech-assets.json纳入成品。运行游戏不需要安装模型。

本轮云端标签切换后仍报告页面可见，因此后台自动停止未获得实机通过证据；窗口关闭、切题及停止按钮已单独验证。

## 2.5.1 图示加载反馈

图集初次下载时显示“图示载入中”，加载成功才显示完整插画；失败或等待超过10秒时明确提示可先读文字题干，之后重新进入题目会重试。已加载图集会在当前页面内复用。图示状态不改变答案、存档或战斗规则。

## 2.5.2 中断与存档连续性

多标签更新后重新安排电脑回合；弹窗打开、页面收到隐藏事件后，旧计时回调不能继续推进。复习作答先读取最新学习汇总，避免旧副本覆盖另一窗口的进度。确认恢复先完成浏览器写入再切换当前存档，写入失败会明确提示尚未恢复；较早的文件读取不能覆盖后选文件，也不能在离开后重新弹窗。导入同时校验课程类型、随从序号和胜负生命的一致性，异常局面不会进入游戏。坏档原始备份仍保留可导出。规则和电脑策略未改变。

## 2.6 单活动窗口与短屏布局

支持Web Locks的浏览器中，同一来源只有一个游戏页能写入存档。另一页显示交接入口；点击后先停旧页操作，再交出锁，新页读取最新存档。已暂停的旧页不能继续AI、播放英语或提交操作。页面关闭释放锁，返回时重新确认；超时或未保存数据不会强行抢走写入权。协调消息只含随机窗口标识、类型和截止时间，不含昵称或学习记录。

首次打开本版请关闭仍在运行的旧版页面，旧代码不认识新的保护。没有Web Locks时仍可单页使用，但会在设置中明确说明限制；锁服务异常时先阻止写入，只有使用者确认已关闭其他游戏页才进入单页后备。不保证跨浏览器、旧版本或不支持锁的多页并行安全。接口依据：https://www.w3.org/TR/web-locks/ 。

桌面短屏将交战提示与操作条共用一行，保留手牌字号；特定横屏范围内为完整手牌预留底部空间。长语境题改用紧凑的仪式标题，保留英语正文与选项字号。具体视口与题型仍以实测说明为准，不把CSS范围声明当作真机通过。

2.6.1修正火花选目标时的说明：法术可以越过守卫直击英雄，普通攻击才需要先破守卫。规则实现未改动。

2.6.2整理短屏选目标操作条的内边距，将条带放在单位数值下方；取消与施放仍保留44px点击高度，卡牌和英文字号不变。

## 2.7 起手选择和旧规则兼容

新开局采用规则2.1：从4张起手中免费选0–2张换掉，先取替代再把旧牌放回确定性洗牌。可能得到同名副本，不保证每局有1费牌。确认只生效一次，保存后不能撤销重抽；玩家仍以4张/1能量开始，电脑自己的第一回合才正常补第5张。电脑用自己的4张手牌安排低费曲线，不读取玩家手牌或未来牌库。

Ember只在2.1中略提高对敌方场上随从的重视，避免轻易放过能反复攻击的小随从。没有增加生命、费用优惠或额外仪式；也没有采用更激进的早期技能储备加成。它仍可能较早用完仪式，不是最优策略承诺。

旧2.0未完局不重新发牌、不补换牌，继续原4次资源、原AI估值和原分数；1.0也保留其原始资源与计分。2.1当前榜和历史规则分开，历史可选1.0或2.0，原成绩保留。迁移回归与冻结的2.0引擎逐状态对照，不通过改写旧规则版本冒充兼容。

为隔离不认识新档的旧页面，2.7使用新版专有的存储、写入锁和页间消息通道。旧页面不能占据新版队列或覆盖新版档案；原旧档不删除，但后续新旧进度不自动合并。支持锁的新版页面之间可正常交接；无锁浏览器仍只建议单页。请先关闭旧页面，再继续新版。

## 2.7.1 中断清理与复习反馈

离开战场或交接窗口时，冲撞/弹道到达的旧回调不能再产生命中光效与声音，未开始的胜利彩粒也被取消。当前规则和计分不变。

当日答错再改对，不额外增加熟练阶段，但会安排至少1天后的复习。手册按每轮最多6项安排，本轮不重复；跳过不计作答，答错项下一轮仍可再练。每轮结束可返回手册休息或主动再练。没有到期内容时，手册明确显示本轮已完成。排行榜如实标明“近200局内个人最佳”，不把有限保存的记录称为永久最佳。

## 2.7.2 保存异常恢复和窄屏调牌

## 2.7.4 退场数字归属

实际试玩发现退场伤害数字比随从重排停留更久，会短暂盖在移入同一槽位的伙伴上。现在退场数字在420毫秒内先消散，早于存活伙伴开始移动；存活单位和英雄的提示时长不变。数值标记按单位归属管理，发生重排时清除之前动作遗留的单位标记，快速连续出牌和减少动态也不会把旧数字留给新占位者。

战场或结算进入手册、挑战榜时沿用该局真实年级及范围；旧规则成绩自动定位历史分区。营地入口使用营地当前选择，续局按钮注明旧局真实年级/范围。只切换营地年级不会改变未完局；课程说明返回手册保留正在浏览的范围。
