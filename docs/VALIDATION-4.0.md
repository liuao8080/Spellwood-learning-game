# 4.0.0-alpha.1 验证记录

更新于2026-10-08。此文件只描述开发分支；公开电脑试玩仍为3.2.9，未接入本轮后端。

## 已实测

- 实际Node HTTP/WebSocket：不同Cookie的游客匹配、动作/判题权威、隐藏手牌、重连、电脑回退、完整协议对局
- 实际SQLite：游客注册保留playerId、跨会话登录读取进度、退出隔离、会话/恢复码撤销、迁移事务与失败回滚
- 实际生产IdentityClient与RemoteProgressStore经HTTP调用：学习回执读取、重复礼盒固定结果、断线人类席终局保存、暂时写失败保留待同步
- 独立审查实际复现并修正：旧页在新Cookie下误写新档；恢复码跨身份残留。修后归属检查发生在写入前
- 原有DOM模型/场景/规则回归适配了真实身份初始化。模型测试不是浏览器截图

2026-10-08 08:51 UTC：679项串行Node回归全部通过，typecheck、旧离线构建/check、网络构建和电脑试玩构建通过。Playwright仅执行了test --list，确认5组测试可发现；尚未执行浏览器。typecheck范围仍主要为旧核心JSDoc接口，不能当全服务静态类型证明。

本轮共享环境串行检查共约72秒，监测到的自身子树RSS峰值约359MiB。它是100ms抽样值，不能代表浏览器内存或宿主硬上限。

## 本轮浏览器计划

GitHub标准Ubuntu临时runner：独立Cookie/browser contexts，虚构账号，可见注册、两客户端匹配与实际出牌/攻击/英语题、自然终局、断网重连、默认10秒电脑后备、SQLite重启后账号进度保留、320/390/844尺寸截图。测试不读取私有题库答案、注入引擎状态或使用本地存储假装联网。

只有人工核过的安全截图和非敏感报告可上传；不上传数据库、Cookie、恢复码、密码、HAR或trace。实际GPU/WebGL是否可用以截图和渲染器结果为准，不从Three.js依赖推断。
