# 3.1 真实试玩证据

这些图片来自公开电脑试玩的实际浏览器画面，日期为2026年10月7日。运行的是云端Chromium的CPU兼容三维路径，不是WebGL像素、离线渲染或物理手机触控。

- fire-flight / fire-impact：实体火团起飞、抵达、命中圆环与伤害反馈
- water-flight / water-impact：海獭发射水滴，命中水环和伤害，护盾消耗依规则结算
- victory：默认自适应轻松局自然完成10回合，750分，英语4/4。没有重载或跳过战斗，单次独立自助试玩不能估计学生胜率
- day：真实学习参与累计6个不同知识点后记1个有效学习日。并未实际等待五个日期；五日奖励另有逻辑测试
- mobile：同源iframe中的实际CSS视口，包含选牌、题目、开包；不是设备仿真或物理触控。满八伙伴阵容未穷尽

原始对局图像对应Site v11；v12-lid-light为实际开盖光束、v12-360-units为360×640少伙伴战场。v12的改动是收藏滚动、旧房间过期通知隔离、开包光效、CPU稳定光照缓存与标准档仪式频率小调；最终限定复验结果在交付验证说明中。前轮2.7.5与3.0资料另存，不能作为新增功能通过的证据。
