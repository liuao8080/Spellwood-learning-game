这是可迁移的三维匹配完整源码包。素材与语音均在包内，初次安装Node依赖需要npm。
解压到一个文件夹，安装Node.js24或更高版本，依次运行：
npm ci
npm run build:network
npm run server
然后在服务器同一台电脑打开http://127.0.0.1:4173。两个独立会话选同范围可匹配，默认无人等待10秒进入电脑挑战。
此服务器只保存内存房间，重启会结束未完联网对局；学习记录在浏览器，请使用JSON备份。
旧离线源码也保留，可运行npm run build生成dist/index.html。已交付的2.7.5离线包是独立检查点。
此包不含用户档案、账号凭据或部署到旧站点的配置。Docker模板尚未实际构建。浏览器验收边界见README。
